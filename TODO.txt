How to leave review comments for later: put an HTML comment starting with REVIEW
on its own line next to the text it concerns, for example
  <!-- REVIEW: this paragraph overstates the gain; soften or cite. -->
HTML comments do not appear in the knitted vignette or on the website. Inside a
code chunk use an R comment instead, # REVIEW: ..., which does show in the
rendered code.
